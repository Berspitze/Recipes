# Recipes
This repository stores my liked recipes in a simple and saveable format 
so that I can access it from wherever I like.

# Installation
Install [cookcli](https://github.com/cooklang/cookcli)
```bash
git clone git@github.com:Berspitze/Recipes.git
cd ./Recipes
cook server
```
Then put `http://127.0.0.1:9080/` into your browser to see recipes.
